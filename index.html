Semua Kamera

Webcam USB & kamera bawaan HP (front / back / lainnya)

Kamera HTTP (MJPEG / IP cam)

Contoh stream dengan Basic Auth. Di HP, 127.0.0.1 = perangkat itu sendiri. Jalankan halaman lewat node server.mjs agar deteksi & preview tidak kena CORS.

Kamera RTSP

Browser tidak memutar rtsp:// langsung. Server convert ke MJPEG via FFmpeg (node server.mjs di PC/Mac). User/password bisa di field atau sudah di URL (rtsp://user:pass@host:554/...).

Tekan Izinkan & tampilkan kamera untuk meminta akses kamera.
Kenapa tidak bisa semua live?
  • Di Android, HAL/driver sering hanya mengizinkan satu pipeline kamera aktif (kadang dua kalau front+back khusus).
  • Browser cuma bisa lewat getUserMedia — tidak bisa “force” buka semua sensor seperti app native Camera2.
  • Snapshot berurutan: buka kamera A → ambil 1 frame → tutup → buka B → … sehingga semua tetap kefoto tanpa bentrok.
  • Satu live: untuk monitoring real-time, pindah kamera tanpa membuka banyak stream.
